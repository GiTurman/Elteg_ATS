# GT-ATS — ქოლ-ცენტრის სატელეფონო სადგური

**ავტორი:** Giorgi Turmanidze "GT"

Asterisk 20 (Docker) + Caddy (ავტომატური HTTPS). ოპერატორები ზარს პასუხობენ და რეკავენ
**პირდაპირ აპიდან** (ბრაუზერის ტელეფონი, WebRTC). ცალკე ტელეფონის აპარატი საჭირო არ არის.

## როგორ მუშაობს

```
აბონენტი → 0322 77 02 00 → ოპერატორის SIP ხაზი → სადგური (Asterisk)
   → ჩაწერა + „საუბარი იწერება“ (თუ ფაილი არსებობს)
   → რიგი: ხაზზე მყოფი ოპერატორები (აპის ტელეფონის პანელი, „ხაზზე“ ჩართული)
   → QUEUE_TIMEOUT წამში პასუხი არ არის → აპის „ცვლებით“: ხელმძღვანელი → მორიგე ტექნიკოსის მობილური
   → ისევ არა → „ყველა დაკავებულია“ → აპში „უკან დასარეკი“
ყველა მოვლენა და ჩანაწერის ბმული ავტომატურად ჩადის აპის „ზარების ისტორიასა“ და KPI-ში.
```

- **ოპერატორები ავტომატურად:** სადგური ყოველ წუთში ითხოვს აპიდან სიას. ვისაც აქვს შიდა ნომერი,
  მას ავტომატურად ექმნება SIP ანგარიში. ოპერატორები (დისპეჩერის როლი) ავტომატურად ხვდებიან რიგში.
- **გამავალი ზარი:** აპიდან (ტელეფონის პანელი, „უკან დასარეკი“, ზარების ისტორია) → კლიენტი ხედავს მთავარ ნომერს.
- **შიდა ზარი / გადართვა:** შიდა ნომრით (მაგ. 100 — ხელმძღვანელი).

## რა არის საჭირო

1. **სერვერი (VPS):** Ubuntu 24.04, 2 GB RAM, საჯარო IP. მაგ. Hetzner CX22 (~€5/თვე) ან ნებისმიერი ქართული ჰოსტინგი.
2. **დომენი:** მაგ. `pbx.თქვენიდომენი.ge` (DNS A-ჩანაწერი სერვერის IP-ზე).
   დომენი თუ არ გაქვთ: გამოიყენეთ `<IP-ტირეებით>.sslip.io` (მაგ. `203-0-113-10.sslip.io`). უფასოა და DNS არ სჭირდება.
3. **ოპერატორის SIP ხაზი** ნომერზე 0322 77 02 00: სერვერი, მომხმარებელი, პაროლი.

## დაყენება (ერთხელ, ~15 წუთი)

სერვერზე (SSH, root):

```bash
# 1. Docker
curl -fsSL https://get.docker.com | sh

# 2. კოდი
git clone https://github.com/GiTurman/Elteg_ATS.git
cd Elteg_ATS/pbx

# 3. პარამეტრები
cp .env.example .env
openssl rand -hex 16            # ← ეს ჩაწერეთ REC_SECRET-ში
nano .env                       # შეავსეთ: WEBHOOK_TOKEN, PBX_DOMAIN, PUBLIC_IP, REC_SECRET, TRUNK_*

# 4. ფაიერვოლი
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp
ufw allow 10000:10200/udp
ufw allow from <ოპერატორის-SIP-IP> to any port 5060 proto udp
ufw --force enable

# 5. გაშვება
docker compose up -d --build
docker logs -f gt-ats-asterisk   # უნდა გამოჩნდეს: „GT-ATS: სადგური ეშვება“
```

აპში: **ტელეფონია → სატელეფონო სადგური** ველში ჩაწერეთ:
- სადგურის მისამართი: `wss://<PBX_DOMAIN>/ws`
- მთავარი ნომერი: `0322770200`

შემდეგ ოპერატორები განაახლებენ გვერდს (F5) და ტელეფონის პანელში ჩართავენ **„ხაზზე“**.

## შემოწმება

```bash
docker exec -it gt-ats-asterisk asterisk -rx "pjsip show registrations"   # trunk-reg → Registered
docker exec -it gt-ats-asterisk asterisk -rx "pjsip show contacts"        # ხაზზე მყოფი ოპერატორები
docker exec -it gt-ats-asterisk asterisk -rx "queue show hotline"         # რიგი და წევრები
docker exec -it gt-ats-asterisk tail -n 50 /var/log/asterisk/pbx-notify.log  # webhook-ის შეცდომები (თუ არის)
```

## განახლება

cd Elteg_ATS && git pull && cd pbx && docker compose up -d --build

## უსაფრთხოება

- 5060/udp ღიაა **მხოლოდ** ოპერატორის IP-სთვის (ფაიერვოლი). ოპერატორები უკავშირდებიან მხოლოდ WSS-ით (HTTPS).
- SIP პაროლები 24-ნიშნაა, გენერირდება აპის სერვერზე და არავის სჭირდება ხელით.
- ჩანაწერების ბმული შეიცავს საიდუმლო ნაწილს (REC_SECRET). ჩანაწერები ავტომატურად იშლება REC_RETENTION_DAYS დღის შემდეგ.
- `.env` ფაილი არ ატვირთოთ GitHub-ზე (`.gitignore`-შია).
