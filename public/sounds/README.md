# ხმოვანი შეტყობინებები

ავტორი: Giorgi Turmanidze "GT"

ამ საქაღალდის ფაილებს ერთდროულად იყენებს:
- **აპი** — „ტელეფონია“ გვერდზე, ბარათში „ხმოვანი შეტყობინებები“ (მოსასმენად);
- **სადგური** (Asterisk) — `pbx/docker-compose.yml` ამ საქაღალდეს აბონენტისთვის დასაკრავად იყენებს.

ფორმატი: **WAV, 8000 Hz, mono, 16-bit** (ასეთ ფაილს ბრაუზერიც უკრავს).

| ფაილი | ტექსტი |
|---|---|
| `recording-notice.wav` | „გამარჯობა, თქვენ დაუკავშირდით კომპანია ელტეგს. საუბარი იწერება ხარისხის გაუმჯობესების მიზნით. თუ არ გსურთ საუბრის ჩაწერა, გთხოვთ, დაგვიკავშირდეთ ალტერნატიული საშუალებით.“ |
| `all-busy.wav` | „ამჟამად ყველა ოპერატორი დაკავებულია. თქვენი ზარი დაფიქსირდა და მალე დაგიკავშირდებით.“ |

ტექსტის წყარო აპში: `src/components/telephony/VoicePromptsCard.tsx` (`VOICE_PROMPTS`).

კონვერტაცია ნებისმიერი ჩანაწერიდან (mp3, m4a):
`ffmpeg -i ჩანაწერი.mp3 -ar 8000 -ac 1 -sample_fmt s16 recording-notice.wav`

ფაილის არარსებობის შემთხვევაში სადგური ამ ნაბიჯს უბრალოდ გამოტოვებს.

> მიმდინარე ფაილები სინთეზურია (eSpeak NG, ქართული ხმა, 8 kHz) — დროებითია. ცოცხალი ჩანაწერით ჩანაცვლებისას შეინარჩუნეთ იგივე სახელები.
